## ✦ Về mình

Mình là **Trần Quang Thanh** — một người đang trên hành trình trở thành lập trình viên, với định hướng **Full-stack Development** và **Automation Engineering**.

Mình không coi lập trình chỉ là việc gõ code cho chạy được. Với mình, đó là quá trình **hiểu vấn đề → thiết kế giải pháp → viết code → kiểm thử → sửa lỗi → học lại từ đầu nếu cần**. Mỗi bug là một bài học, mỗi commit là một bước tiến nhỏ nhưng thật.

Hiện mình đang xây nền tảng vững qua **Java**, **Python**, **Web Development** và **Automation Testing** — học song song lý thuyết và thực hành, ưu tiên làm thật, commit thật, sửa thật.
